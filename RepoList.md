# RepoVault - AI Engineering Applications

This repository contains a diverse collection of AI-powered applications and tools built with modern frameworks and technologies. Each project demonstrates different aspects of AI engineering, from chatbots and agents to content creation and analysis tools.

## Applications Overview

### 🚀 Streaming & Real-time AI
- **Streaming AI Chatbot** - Real-time AI streaming with conversation state management using Motia framework
- **Ultimate AI Assistant (MCP)** - Multi-MCP server integration with chat interface for tool access

### 📊 Financial & Analysis Tools
- **Stock Portfolio Analysis Agent** - AI agent for streaming portfolio analysis with CrewAI and React frontend
- **Amazon Product Analysis Server** - MCP server for comprehensive Amazon product insights with React widget
- **Financial Analyst (DeepSeek)** - AI-powered financial analysis and insights

### 🤖 Agent & Workflow Builders
- **Open Agent Builder (with Composio)** - Visual workflow builder for creating AI agent pipelines with drag-and-drop interface
- **CrewAI Stock Analyst** - Multi-agent system for stock market analysis
- **Agentic RAG (DeepSeek)** - Retrieval-augmented generation with DeepSeek integration

### 💬 Content Creation & Automation
- **Motia Content Creation** - Social media automation workflow for Twitter threads and LinkedIn posts
- **AI Podcast Generator** - Automated podcast creation from text content
- **Book Writer Flow** - AI-powered book writing and content planning

### 🔗 Web Browsing & Automation
- **Web Browsing Multi-Agent Workflow** - Local browser automation using CrewAI and Stagehand
- **Stagehand MCP** - Browser automation with MCP protocol integration
- **Firecrawl Agent** - Web scraping and content extraction agent

### 🧠 Memory & Context Management
- **Zep Memory Assistant** - AI agent with human-like memory using Zep's long-term memory backend
- **Trustworthy RAG** - Reliable retrieval-augmented generation with memory persistence
- **Database Memory Agent** - Context management using database storage

### 🌐 Multi-modal & Voice
- **Real-time Voicebot** - Voice-based AI assistant with real-time processing
- **RAG Voice Agent** - Voice interaction with retrieval-augmented generation
- **MCP Voice Agent** - Voice-enabled MCP server integration

### 📄 Document & Content Processing
- **Video RAG (Gemini)** - Video content analysis and retrieval-augmented generation
- **Document Chat RAG** - Document-based chat and analysis
- **LaTeX OCR with Llama** - Optical character recognition for mathematical content

### 🔐 Local & Private AI
- **Local ChatGPT (Gemma 3)** - Local LLM deployment with Gemma 3 model
- **Local ChatGPT (DeepSeek)** - Local LLM deployment with DeepSeek model
- **Fastest RAG Stack** - Optimized retrieval-augmented generation pipeline

### 🔧 Development & DevOps
- **AI Engineering Roadmap** - Learning path and project templates for AI engineering
- **Build Reasoning Model** - Custom model training and fine-tuning workflows
- **Code Model Comparison** - Benchmarking and comparison of different AI coding models

### 🛠️ Specialized Tools
- **Siamese Network** - Similarity learning and comparison tool
- **Paralegal Agent Crew** - Legal document analysis and research automation
- **Brand Monitoring** - Social media and brand presence tracking
- **AI News Generator** - Automated news content creation

## Common Technologies Used

- **Motia** - Unified backend framework for AI applications
- **CrewAI** - Multi-agent orchestration system
- **MCP (Model Context Protocol)** - Standardized tool integration
- **LangGraph** - Workflow orchestration engine
- **Next.js/React** - Frontend development
- **Ollama** - Local LLM serving
- **Firecrawl** - Web scraping and content extraction
- **Stagehand** - Browser automation
- **Zep** - Long-term memory management

## Getting Started

Each application has its own setup instructions in its respective README.md file. Most projects follow a similar pattern:

1. Install dependencies using `uv sync` or `npm install`
2. Configure environment variables (API keys, model settings)
3. Start the development server
4. Access the application via provided URL
